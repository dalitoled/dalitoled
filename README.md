## 🌟 Proyectos Destacados

### 🍄 [Sistema IoT de Control Ambiental](https://github.com/dalitoled/proyecto_hongos)
> **Proyecto de Titulación en Ingeniería de Sistemas**  
Sistema automatizado de control de microclimas para cultivo controlado de hongos comestibles (*Pleurotus ostreatus*) en invernadero piloto de 32 m².
- **Hardware:** Microcontrolador ESP8266 programado en C++ (Arduino Framework), sensores DHT22 (temperatura/humedad) y LDR, control de actuadores vía relés (ventiladores, calefacción, bomba de aspersión).
- **Software:** App móvil en Ionic / Angular, dashboard web en React y sincronización en tiempo real con Firebase RTDB.
- **Impacto medido:** **+67% de aumento en rendimiento de cosecha**, **-20% de reducción en ciclo** y **20% de ahorro energético**.

### 💧 [Sistema de Gestión & Control de Asistencia QR](https://github.com/dalitoled/asistencia_qr_flutter)
> **Solución Móvil & Cloud para Comunidades de Agua Potable**  
Aplicación móvil corporativa para el control de más de 500 socios, asambleas y recaudación financiera.
- **Stack:** Flutter (Dart), arquitectura Riverpod, Firebase Firestore y Cloud Functions.
- **Características:** Generación y escaneo dinámico de códigos QR, **modo offline resiliente** para zonas rurales sin cobertura y exportación de planillas a PDF/Excel.

### 🐔 [AviGest - Trazabilidad y Logística Productiva](https://github.com/dalitoled/granja_avicola_ios)
> **Plataforma Integral de Gestión Agroindustrial**  
Software para control de ciclos productivos avícolas, pesajes en tiempo real, curvas de crecimiento, mermas y auditoría de inventario.
- **Stack:** React, Node.js, Microsoft SQL Server y aplicación móvil en Flutter.
